# **Système RH Intelligent — JavaFX**

## **Présentation**

Système RH Intelligent est une application de bureau développée en Java avec JavaFX, conçue pour faciliter la gestion des ressources humaines et moderniser le processus de recrutement.

Le projet met l'accent sur **l'analyse des CV** afin d'aider les recruteurs à examiner les candidatures, à identifier les profils pertinents et à faciliter la présélection des candidats en fonction des besoins du poste.

L'objectif est de rendre le processus de recrutement plus structuré, efficace et accessible grâce à une interface graphique intuitive.

## **Fonctionnalité principale : Analyse intelligente des CV**

Le système vise à faciliter l'exploitation des candidatures et l'analyse des profils professionnels afin d'aider les recruteurs dans leur prise de décision.

Cette approche permet notamment de :

- **Faciliter l'examen des CV** des candidats.
- **Identifier les informations pertinentes** des profils.
- **Rapprocher les compétences** des candidats des exigences d'un poste.
- **Simplifier la présélection** et améliorer l'organisation du recrutement.

> L'analyse automatisée constitue une aide à la décision et ne remplace pas l'évaluation humaine des candidatures.

## **Technologies utilisées**

- **Java** — logique applicative.
- **JavaFX** — création de l'interface graphique.
- **FXML** — description des interfaces utilisateur.
- **Apache Ant** — automatisation de la compilation.
- **NetBeans** — environnement de développement.

## **Structure du projet**

- `src/` — code source Java et fichiers de l'application.
- `resources/` — ressources nécessaires à l'interface et au fonctionnement du système.
- `nbproject/` — configuration du projet NetBeans.
- `build.xml` — script de compilation et de construction.
